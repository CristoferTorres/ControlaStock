## Descripción

ControlaStock es un sistema web diseñado para pequeñas tiendas y misceláneas. Permite gestionar el inventario en tiempo real, registrar ventas, controlar clientes y proveedores, y consultar reportes para tomar mejores decisiones de negocio.

---

## Funcionalidades

- Gestión de inventario con alertas de stock bajo
- Registro de ventas y generación de tickets
- Administración de clientes y cuentas por cobrar
- Control de proveedores y compras
- Reportes y estadísticas de ventas
- Gestión de usuarios con roles y permisos
